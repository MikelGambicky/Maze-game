# Maze Survival Game (working title)

A first-person multiplayer roguelike maze survival game built in Unity.

## Status

Early development.

## Game design

Players are dropped into a maze and have to survive. Each run is different, and dying means starting over.

- **Procedurally generated mazes:** a new layout every run
- **Enemies:** monsters hunting the player through the maze
- **Items and upgrades:** pickups to find and use along the way
- **Multiplayer:** play co-op with friends or compete against other players
- **Permadeath:** die and you restart with a fresh run
- **Resource management:** keep track of survival resources such as health and stamina
